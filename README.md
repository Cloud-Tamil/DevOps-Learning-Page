# DevOps Learning Hub

A hands-on learning repository for building practical DevOps skills through notes, experiments, and step-by-step guides.

## Learning Focus

- **Docker:** images, containers, registries, networking, volumes, and Compose
- **Kubernetes:** core resources, deployments, services, probes, and application operations
- **CI/CD:** GitHub Actions and Jenkins pipeline fundamentals
- **Infrastructure as Code:** Terraform concepts and repeatable infrastructure workflows
- **Cloud platforms:** AWS, Azure, and Google Cloud learning paths
- **Operations:** Linux, troubleshooting, monitoring, and secure configuration

> This repository is a learning workspace. Check the folders and individual guides for the topics currently implemented; the list above describes the broader learning direction.

## Getting Started

1. Browse the repository folders and choose a topic.
2. Follow the guide's prerequisites before running commands.
3. Test examples in a local or disposable environment.
4. Record errors, fixes, and useful commands as you learn.
5. Never commit credentials, access keys, tokens, or real environment files.
